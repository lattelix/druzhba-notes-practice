# Дружба Notes

Учебный проект по производственной практике направления 09.03.02 «Информационные системы и технологии», профиль «Веб-разработка».

## Состав

- `notes-app` - приложение заметок на Expo и React Native;
- `expert-system` - браузерный прототип оценки готовности ИТ-инфраструктуры;
- `docs` - сайт-презентация для GitHub Pages;
- `materials` - презентация, скриншоты и пояснения к кейсам.

## Запуск приложения заметок

```bash
cd notes-app
npm install
npm run web
```

## Экспертная система

Откройте `expert-system/index.html` в браузере или запустите простой статический сервер из корня репозитория.
