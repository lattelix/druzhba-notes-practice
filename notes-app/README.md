# Дружба Notes

Мобильное приложение для создания, редактирования, поиска и удаления рабочих заметок.

## Команды

```bash
npm install
npm run web
npm run typecheck
npm run lint
npm run export:web
```

В iOS и Android метаданные заметок хранятся в SQLite, содержимое хранится в файлах приложения. В веб-сборке используется `localStorage`.
